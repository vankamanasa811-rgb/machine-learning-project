# 📊 Telco Customer Churn Prediction

## Project Overview

This is a Machine Learning project that predicts whether a telecom customer is likely to churn.

The project uses customer information from a Telco Customer Churn dataset and applies machine learning techniques to make predictions.

##  Objective

The main objective of this project is to identify customers who are likely to leave the telecom service.

This can help companies understand customer behavior and take steps to improve customer retention.

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Machine Learning Algorithms

The project includes:

- Linear Regression
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree

##  Project Files

- `AIML_project.ipynb` — Complete Machine Learning analysis and model building
- `app.py` — Streamlit web application
- `WA_Fn-UseC_-Telco-Customer-Churn.xlsx` — Dataset
- `.gitignore` — Files excluded from GitHub

##  Model Performance

The current application shows a test accuracy of approximately:

**80.55%**

## Streamlit Application

The Streamlit application allows users to enter customer information and receive a customer churn prediction.

### Main Features
